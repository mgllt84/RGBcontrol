RGBCcontrol — dossier des pilotes
=================================

Placez ici chaque package de pilote validé : son fichier .rgbcplugin et son
exécutable. RGBCcontrol analyse automatiquement les sous-dossiers.

Un appareil n'apparaît que si :
- son VID/PID correspond exactement au manifeste ;
- l'empreinte SHA-256 de l'exécutable est correcte ;
- le pilote répond correctement à la commande de test « probe ».

Consultez ..\PLUGIN-SDK.md pour le format complet.

Ne copiez pas ici les fichiers internes d'un logiciel constructeur ou de
SignalRGB. Seuls les pilotes dont la licence autorise la redistribution peuvent
être fournis avec RGBCcontrol.
